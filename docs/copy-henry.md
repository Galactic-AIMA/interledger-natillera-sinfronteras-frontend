## Consistencia

- Una sola palabra por concepto: **natillera** (no "fondo") para el grupo; **billetera** para la cuenta de cada quien; **cuota** para el aporte periódico.
- Montos siempre con moneda visible ("$50.000", "11,00 €", "24,88 US$"); nunca "USD 24.88".
- Botones con verbo y destino: "Poner la cuota", "Enviar a Luz", "Autorizar las cuotas".
