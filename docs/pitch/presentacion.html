Cómo se usa

  • Pasar diapositiva: botón Siguiente →, flecha →, espacio o el control remoto (clicker). En el celular, deslice el dedo.
  • Volver: ← Atrás o ←.
  • Pantalla completa: F. Los botones se esconden solos; mueva el mouse para verlos.
  • Notas (N): lo que se dice en cada diapositiva y un cronómetro.
  • Tema: cambie la apariencia completa. Hay cinco para decidir con el equipo.
  • ✎ Editar (E): cambie textos, imágenes, notas y el orden; agregue o quite diapositivas. También puede escribir directo sobre la diapositiva. Se guarda solo en este navegador.
  • Guardar PDF: una diapositiva por hoja, para subir al Drive o a Google Slides.
